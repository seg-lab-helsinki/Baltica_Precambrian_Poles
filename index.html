Baltica Precambrian Pole Compilation

Database-linked working resource for the Baltica Precambrian paleomagnetic pole compilation, including a master pole table, linked site-level data, interactive map, paleolatitude figure, and pole-assessment pages.

Overview

This webpage provides a working online interface for the Baltica Precambrian pole compilation. The source data are maintained in the repository, and the main web outputs are regenerated from the data files. The current pole count should be checked from the searchable pole compilation page, which is generated from the current web-ready pole table.

Current source files: data/Table1_Salminen_etal_2027.xlsx, data/Baltica_poles.csv, data/site_level_data_site_comments_added.xlsx, data/pole_sheet_match.csv, data/pole_assessment_notes_template.csv, and data/vgp_attention_tracker.csv.

Online resource structure

The resource is organized around a master pole table and a linked site-level working database. These data are used to generate online outputs for inspection, documentation, and quality checking.

Master pole table
Pole name, terrane, nominal age, age range, reliability grade, sampling locality, pole coordinates, A95, and reference information.
Site-level working database
Recovered site-level directions, VGPs, metadata, age information, magnetization comments, and study-specific notes where available.
Web outputs
Searchable pole compilation table, interactive sampling-locality map, paleolatitude figure, and pole-assessment pages.

Pole-assessment pages

The pole-assessment pages are designed to link pole-level metadata to the recovered site-level information and graphical summaries where available.

Each pole-assessment page follows these headings:

  1. Geological context
  2. Magnetization components
  3. Age constraints
  4. Site-level data
  5. PSV variation
  6. Comparison to Baltica A-/B-grade poles
  7. Comparison to younger Baltica poles
Note: some scientific assessment sections are still being filled and checked. The webpage should therefore be treated as a working database prototype.

Update workflow

The webpage should be updated by editing the source data files first, then rebuilding the generated HTML outputs through GitHub Actions.

1. Edit source data
Update Table 1, the web-ready pole table, site-level workbook, matching table, or assessment-note files.
2. Rebuild outputs
GitHub Actions regenerates the interactive map, pole compilation page, paleolatitude page, and pole-assessment pages.
3. Check webpages
Open the updated pages with a fresh browser refresh or a cache-busting URL to confirm that the newest version is displayed.

Reliability rating

Grade A poles are the most reliable. Grade B poles are retained as likely useful but may lack one or more reliability criteria. Grade C+ entries are retained for review and filtering in the working compilation.
